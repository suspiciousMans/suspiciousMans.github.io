#0 · Rust · Toy language · WebAssembly

Oxidized.

A small toy language that transpiles its own .ox syntax into Rust and builds it with rustc. Dynamic by default, statically typed when you ask, with structs, enums, pattern matching and closures.

Try it here ↓ Source ↗
counter.oxrs
struct Counter {
    n: Int
}

impl Counter {
    fn inc(self) {
        self.n = self.n + 1
    }
}

fn main() {
    let c = Counter(n: 0)
    c.inc()
    c.inc()
    print("rusted", c.n, "times")
}
oxidized runx
> counter.ox rusted 2 times
#1 · What it takes a stance on

Built to corrode
gracefully.

#01

Compiles to Rust

A hand-rolled lexer, recursive-descent parser and checker turn .ox into Rust source, and rustc does the rest. Add --wasm and it targets WebAssembly instead.

#02

Dynamic until you pin it

Values are dynamic by default. Annotate a variable, parameter or return as i32, Int, Float or String and it becomes a real Rust type, converted at the boundary.

#03

Structs, enums, match

Structs with impl methods, enums with payloads, and match as an expression, checked for exhaustiveness. Errors come back as a built-in Result.

#04

Closures that remember

fn(x) { ... } lambdas capture by value and keep their own state across calls, so a counter factory works the way you'd hope.

#3 · Language reference

The short
version.

Semicolons are optional, and code lives inside fn main().

let x = 5
let y: i32 = 5

Dynamic by default, or pinned with a type: i32, i64/Int, f64/Float, bool, String, List. Using let again on a name reassigns it, and so does x = 10.

fn add(a: i32, b: i32) -> i32 { ... }

Functions, typed or untyped, and nestable. A typed function must return on every path. Untyped ones can be passed around as values.

if x > 0 { } else { }
while x > 0 { }
for i in range(0, 10) { }

No parentheses around conditions. for walks a List, range(a, b) makes one, and break/continue work in loops.

struct Point { x: Int, y: Int }
Point(x: 3, y: 4)

Built with parentheses and named fields. p.x = 5 updates a variable's field, and structs are copied when passed.

impl Point { fn dist(self) { ... } }

Methods take self first. Assigning to self's fields updates the caller's variable.

enum Shape { Circle(Int), Point }
match s { Circle(r) => r, _ => 0 }

Variants are built as Shape::Circle(5), always with parentheses. match is an expression over variants, literals, a catch-all name or _, and must cover every variant.

let add = fn(a, b) { return a + b }

Lambdas capture the variables they use by value when they're created, and keep their own changes across calls.

3.7 as Int
"42" as Int

Casts between Int, Float, String and bool. Int and Float don't mix in arithmetic without one.

fn identity<T>(x: T) -> T

Generic functions and structs, checked for consistency within a call.

len push slice range
map_new map_set map_get map_has

Lists, strings and maps are values: push and map_set return a new one, so write xs = push(xs, 4). Also map_remove, map_keys, map_values.

abs min max sqrt pow floor ceil round
upper lower trim split join contains replace

Math and string builtins, plus starts_with and ends_with. print takes any number of values and assert(cond, msg) panics when false.

parse_int checked_div map_try_get
unwrap unwrap_or is_ok is_err

Functions that can fail return Result::Ok(v) or Result::Err(msg). Everything else that goes wrong panics, including integer overflow and division by zero.

import "math.ox"
import "shapes.ox" as shapes

Pulls in another file's declarations, optionally under a namespace (shapes::area(c)). Needs real files, so it only works with the CLI.

# comment
// comment

Both start a line comment.

#4 · Run it for real

Build it.
Run it. Watch it rust.

Build the compiler with cargo build --release, then:

oxidized run hello.ox           # compile with rustc and run
oxidized build hello.ox         # write the generated hello.rs
oxidized check hello.ox         # typecheck only
oxidized run hello.ox --wasm    # build for wasm32-wasip1, run under Node
