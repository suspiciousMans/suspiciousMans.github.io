#0 · Rust · Toy language · WebAssembly

Oxidized.

A small toy language that transpiles its own .ox syntax into Rust and builds it with rustc. Dynamic by default, statically typed when you ask, with structs, enums, pattern matching and closures, plus traits, operator overloading, tuples, ? error propagation and a standard library for files, JSON and text.

Try it here ↓ Source ↗
counter.oxrs
struct Counter {
    n: Int
}

impl Counter {
    fn inc(self) {
        self.n = self.n + 1
    }
}

fn main() {
    let c = Counter(n: 0)
    c.inc()
    c.inc()
    print("rusted {c.n} times")
}
oxidized runx
> counter.ox rusted 2 times
#1 · What it takes a stance on

Built to corrode
gracefully.

#01

Compiles to Rust

A hand-rolled lexer, recursive-descent parser and checker turn .ox into Rust source, and rustc does the rest. Add --wasm and it targets WebAssembly instead. The generated Rust compiles warning-free for every example.

#02

Dynamic until you pin it

Values are dynamic by default. Annotate a variable, parameter or return as i32, Int, Float or String and it becomes a real Rust type, converted at the boundary. The checker now catches far more mistakes before rustc runs.

#03

Patterns that go deep

Nested patterns, struct-style enum variants, tuple patterns and if guards, with exhaustiveness checked all the way down. if is an expression too.

#04

Traits and operators

Traits with default methods and bounds, generic impls, and overloadable + - * /, == and < for your own structs.

#05

Errors with ?

A built-in Result, a postfix ? that returns the error early, and fallible versions of the panicking builtins. An Err that escapes main exits with status 1.

#06

Batteries included

Hash-indexed maps with O(1) lookups, files, JSON, time, text helpers and a tiny HTTP client, all in plain Rust with no external crates. oxidized fmt formats your code.

#3 · Language reference

The short
version.

Semicolons are optional, and code lives inside fn main().

let x = 5
let y: i32 = 5
x += 1

Dynamic by default, or pinned with a type: i32, i64/Int, f64/Float, bool, String, List. Using let again on a name reassigns it, and so do x = 10 and += -= *= /= %=.

fn add(a: i32, b: i32) -> i32 { ... }
const fn square(n: Int) -> Int { ... }

Functions, typed or untyped, and nestable. A typed function must return on every path. Calls to a const fn with literal arguments are folded at compile time.

if x > 0 { } else { }
let s = if ok { "y" } else { "n" }
for i in 0..10 { }

No parentheses around conditions. if works as an expression when it has an else. for walks a List, a..b is a range, and break/continue work in loops.

"{name} is {age + 1}"
"{{literal}} braces"

String interpolation: any expression in { } is turned into a string. Double the braces for literal ones.

struct Point { x: Int, y: Int }
Point(x: 3, y: 4)
xs[i].x = 5

Built with parentheses and named fields. Assignment reaches through any path rooted at a variable: o.p.x = 1, grid[r][c] += 1. Structs are copied when passed. Box<T> lets a struct refer to itself.

impl Point { fn dist(self) { ... } }
impl Cell<T> { ... }

Methods take self first. Assigning to self's fields updates the caller's variable. Impl blocks can be generic.

trait Shape {
  fn area(self) -> Float
  fn name(self) { ... }
}
impl Shape for Rect { ... }

Traits list required methods and can give defaults. fn f<T: Shape + Scalable> bounds a type parameter. Calls dispatch on the value's struct at runtime, so a list of mixed shapes just works.

enum Ev { Click { x: Int, y: Int }, Quit }
Ev::Click(x: 1, y: 2)

Variants carry positional or named payloads and are built with parentheses, even Ev::Quit().

match e {
  Ev::Click { x, y: 0 } => x,
  n if n < 0 => 0,
  _ => { ... }
}

match is an expression over variants, structs, tuples, literals and names, nested to any depth, with if guards and block arms. Coverage is checked when the type is known.

let (q, r) = divmod(17, 5)
t.0
fn f() -> (Int, String)

Tuples are fixed-size groups. Destructure them in a let or a match, index with t.0, and use them as types.

let add = fn(a, b) { return a + b }
(fn(x) { x })(5)

Lambdas capture the variables they use by value when they're created, and keep their own changes across calls. They can be called immediately.

3.7 as Int
"42" as Int

Casts between Int, Float, String and bool. Int and Float don't mix in arithmetic without one.

impl Vec2 { fn __add__(self, o: Vec2) { ... } }

Define __add__ __sub__ __mul__ __div__ __neg__ for arithmetic, __eq__ for ==, and __lt__ for every ordering comparison, including sort.

len push slice range
map_new map_set map_get map_has

Lists, strings and maps are values: push and map_set return a new one, so write xs = push(xs, 4). Maps are hash-indexed and keep insertion order, and also take index syntax: m[k], m[k] = v, m[k] += 1.

abs min max sqrt pow floor ceil round
upper lower trim split join contains replace

Math and string builtins, plus starts_with, ends_with, chars, ord/chr, index_of, sort, sort_by, reverse, sum and the bit operations bit_and bit_or bit_xor bit_not shl shr.

parse_int(s)?
checked_add try_index unwrap_or

Functions that can fail return Result::Ok(v) or Result::Err(msg), and a postfix ? returns the Err from the enclosing function. Also try_slice, checked_sub/checked_mul, map_err, ok_or, unwrap_or_else. Other failures panic, including overflow and division by zero.

read_file write_file list_dir env exit
json_parse json_pretty
pad_left format_float http_get

The standard library: files, environment, time (now_ms, sleep_ms), JSON to and from Maps and Lists, text helpers like split_lines and repeat, and a plain-HTTP client. All of them return a Result rather than panicking.

import "math.ox"
import "shapes.ox" as shapes
fn native seed() -> Int;

Imports pull in another file, optionally under a namespace (shapes::area(c)). fn native declares a function your Rust host provides. Both need the CLI.

# comment
// comment

Both start a line comment.

#4 · Run it for real

Build it.
Run it. Watch it rust.

Build the compiler with cargo build --release, then:

oxidized run hello.ox           # compile with rustc and run
oxidized build hello.ox         # write the generated hello.rs
oxidized check hello.ox         # typecheck only
oxidized fmt --write hello.ox   # format in place (--check for CI)
oxidized run hello.ox --wasm    # build for wasm32-wasip1, run under Node
