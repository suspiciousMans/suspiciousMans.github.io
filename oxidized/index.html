Oxidized.

A small, honest toy language. Ownership-flavored syntax, a real interpreter running in your browser, and nothing that hasn't corroded a little by the time it reaches you. Try it below — let, fn, for i in 0..10, all of it actually runs.

Built to corrode gracefully

A handful of things Oxidized takes a stance on.

Rust-shaped syntax

let bindings, fn declarations, and range loops like 0..10 — familiar if you've written Rust, learnable if you haven't.

Runs where you're standing

The whole interpreter — lexer, parser, evaluator — is a few hundred lines of JavaScript. No server, no build step, no install.

Fails loudly

Divide by zero, call an undefined function, or loop forever — Oxidized surfaces the error instead of silently rusting through.

Deliberately small

Numbers, strings, booleans, functions with closures, if/while/for. That's the whole language.

Playground

Language reference

Everything Oxidized currently understands.

let x = 5;

Declares a variable. Reassign later with x = x + 1;

print(expr);

Writes a value to the output pane. Numbers, strings, and booleans all format sensibly.

if (cond) { ... } else if (cond) { ... } else { ... }

Standard branching. else if chains as far as you like.

while (cond) { ... }

Loops while the condition is truthy. Guarded against infinite loops by an execution-step limit.

for i in 0..10 { ... }

Iterates i over the range, inclusive of the start and exclusive of the end — same convention as Rust.

fn name(a, b) { return a + b; }

Functions, with proper closures — a function can be called before or after other declarations, as long as it exists by the time it's called.

+ - * / % == != < > <= >= && || !

Arithmetic, comparison, and logical operators. + also concatenates when either side is a string.
